Goal is to create a poker evaluator that can handle various kinds of poker variant, not just the usuals
like Texas hold'em, Omaha hold'em, Five-card draw, and so on.

At a bare minimum, I want to be able to support the following:
- Texas hold'em
- Omaha hi-low
- Five-card draw
- Seven-card stud
- Badugi
- Razz
- Six-plus hold 'em
- Lazy pineapple
- Super hold'em
